# 🚗 EV Charging Station Management System

A Java-based console application to manage electric vehicle
charging stations, bookings, and billing.

## Features
- Register/manage charging stations
- Book slots for EVs
- Auto-calculate billing
- View station availability

## Tech Stack
Java | OOP | File Handling | Collections

## How to Run
1. Clone this repo
2. Open in any Java IDE (IntelliJ / Eclipse)
3. Run Main.java
